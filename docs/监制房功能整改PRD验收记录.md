## 横切能力

- 查询与状态、下钻、任务/门禁动作、设置提交、调用详情查看/下载均写入监制审计或遥测；常规遥测只保留允许维度，不记录密钥、完整 prompt 或正文。
- `monitor_audit` 保留对象、结果和关联细节；任务/门禁写操作沿用 capability 权限/批准链，并具备状态前置条件、版本或幂等保护。
- 五个独立发布开关默认开启：`MONITOR_OVERVIEW_V2_ENABLED`、`MONITOR_JOBS_QUERY_V2_ENABLED`、`MONITOR_RUN_CENTER_V2_ENABLED`、`MONITOR_CALL_DETAIL_V2_ENABLED`、`MONITOR_SETTINGS_EDIT_V2_ENABLED`。关闭详情或设置编辑时，服务端同步强制停用敏感读取/写入；关闭任务查询时 UI 不把有限旧数据伪称全量。
- 数据库迁移为幂等新增；旧查询字段保持兼容；需重启设置通过独立 effective 标记在下次启动推进，不伪称即时生效。
