## 私有部署 MiniMax H3（备胎）· exp01-09 实测

单桌面 GPU，ComfyUI 单进程，`max_concurrent_generations=1`，FIFO，**无取消端点**。

| 项 | 结果 |
|----|------|
| reference_images 模式 | ✅ 6/6 成功产出有效 MP4，576×1024 24fps |
| 角色身份保持 | ✅ 强（1 角色与 2 角色+4 参考图均目视确认一致） |
| **场景参考图绑定** | ❌ **弱**：n=2 均出现环境与场景参考图完全不符（金库内景→室外庙门）。环境控制只能靠 prompt |
| 15s 多镜头 | ✅ 可行但弱：quality 档 657s，切点 10.125/13.25 挤末尾 |
| turbo 档位（5s 基线，n=1/档） | balanced 122.5s < quality 158.9s < standard 260.9s；码率与锐度同序 quality > balanced > standard |
| 15s 的 balanced/preview 耗时 | **未解决**：被卡死的高分辨率任务堵死 FIFO（exp08/09 排队 1400s 未启动） |
| 1088×1920 | ❌ 实际卡死 worker（sampling 1120s+ 无进展无报错，疑似 VRAM 抖动），且无法取消 |
| 参考图张数 | 4 张实测可用；4 以上未测 |

## 对代码中硬编码值的裁定

| 代码位置 | 声称值 | 裁定 |
|----------|--------|------|
| `app/video_modes.py:162-164` `max_reference_images()` | 9 | 注释自认是 Seedance 2.0 数字被泛用；H3 从未验证；两家实测上限均未触及（HiAgent 2 张、H3 4 张） |
| `app/config.py:303-306` `VIDEO_DURATION_MIN/MAX_S` | 5/10 | 应用层自限；H3 适配层 `_duration()` 实际收 0.2-15s；HiAgent 实测 15s 可用。P1 轮次改 |

## 对架构的三条硬结论

1. **环境一致性不能押在场景参考图上**（备胎实测无效 n=2；主力未测）。分镜台提示词设计必须保证环境描述在 prompt 里完备；场景参考图作为增强而非依赖。P1 轮次先在 HiAgent 上补测场景绑定再定权重。
2. **接缝时间码是区间不是承诺**（两家一致）。成片拼接/QA 必须事后 scene-detect，不许按指令时间码切。
3. **备胎的运维风险**：无取消端点 + FIFO 单 GPU，一个坏任务堵死整条队列且无 API 自救手段。真切换到私有部署前必须解决（服务端加取消/超时，或部署侧看门狗）。切换时那个卡死的 1088×1920 任务（id 20e669c9-…）可能仍占着 GPU，需服务端处理。
