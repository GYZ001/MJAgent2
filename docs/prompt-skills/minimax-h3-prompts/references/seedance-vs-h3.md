# Seedance 2.0 vs MiniMax H3：对照与迁移

两个模型都做 5-15 秒音视频联合生成，但提示词哲学几乎相反：Seedance 是"中文散文里埋结构暗示"，H3 是"显式结构化字段"。把一边的经验直接套给另一边，多数会失效，个别会起反作用。

---

## 一、逐项对照

| 维度 | Seedance 2.0 | MiniMax H3 |
|---|---|---|
| 提示词形态 | 中文自由散文，段落里嵌"镜头1/镜头2" | 三个命名字段 + `[Shot N]` 官方语法，描述用英文 |
| 时间控制 | 时间码不可靠，只能软提示；节奏靠增减镜头数 | `At 00:03.500` 切点官方支持，严格递增，可精确排片 |
| 多镜头触发 | 靠 15s 时长 + "预告片"暗示词诱发 | 原生，写几个 `[Shot N]` 就是几个镜头 |
| 单镜保障 | 需写"连续单镜头，不切换场景" | 只写一个 `[Shot 1]`；FL2VA 天然偏好单镜 |
| 运镜 | 一镜一运镜词（中文） | 类型+幅度+速度三维英文句；同样一镜一主运镜 |
| 台词 | 写在音频描述里，格式自由 | `(S1)` + `<d>[语言] 原话</d>` 严格语法，支持中文口型 |
| 画面文字 | 汉字必乱码 → 写"无字"，后期合成 | 官方主打能力 → 双引号原文写进提示词（复杂字形先测试） |
| 音频 | "全片贯穿"一段带过 | 拆两个字段：soundscape（剧情内）/ non_diegetic_music（配乐），且必须写 |
| 参考素材 | `@角色名` 引用图片 | 编号素材 + 显式职责声明；图/视频/音频混合参考，V2V 动作迁移 |
| 首尾帧 | 无 | I2VA / FL2VA / L2VA 三种关键帧模式 |
| 局部修复 | 只能整镜重跑 | in-context 编辑（改时间区间/画面区域）+ 768P→2K 再生成 |
| 提示词增强 | 无官方工具 | H3-Context-IR API 可把粗提示词扩写成规范格式 |

## 二、选型

**倾向 Seedance** 当：团队习惯中文散文式创作、不想学结构化语法；素材以单图角色参考为主；目标平台已深度接入 Seedance。

**倾向 H3** 当：
- 分镜需要**精确节奏**（切点到毫秒）——Seedance 做不到；
- 画面里有**必须正确的文字**（品牌、招牌、字幕）；
- 有**对白**且要中文口型；
- 走**首尾帧链**做长内容的跨段一致性（见下）；
- 预算敏感（768P 迭代 + 2K 升清的两段式成本结构）。

小说转短剧这类多段长内容，H3 的首尾帧链是决定性优势：段 N 的末帧作为段 N+1 的 I2VA 首帧，跨段换脸的根因（段间独立采样）被真实画面锚定直接消除。Seedance 只能靠参考图 + 文字描述在每个段边界重新赌一次。

## 三、迁移：Seedance 提示词 → H3

以 novel-to-storyboard 产出的 Seedance 段落提示词为源，机械步骤如下：

1. **拆头**：丢弃"电影级预告片质感，多镜头叙事，镜头之间硬切"这类触发暗示——H3 不需要诱发，多镜头是显式的。风格词保留一个，放进 `[Shot 1]` 开头（如 `Live-action, cinematic`）。
2. **镜头改写**：每个"镜头N（约X-Y秒）"改成 `[Shot N] At 00:0X.000,`（Shot 1 不带时间）。原来的括号软时间在 H3 里升级为真切点——顺手把节奏重新设计一遍，不要照抄。
3. **描述翻译成英文**，台词除外：台词进 `<d>[Chinese] 原话</d>`，屏上文字用双引号原文。
4. **运镜升维**：中文运镜词（"缓慢推进"）映射到三维表达（`pushes in with small amplitude at slow speed`），并改写成句子嵌进动作里。
5. **音频拆两份**："全片贯穿：音频为……"里的环境音、物理声进 `overall_soundscape`；配乐描述进 `non_diegetic_music`，并把情绪词改写成乐器/速度/力度。
6. **约束移位**：Seedance 尾缀里的"面部一致、手指正确、无水印"这类负向约束，H3 没有对应的官方槽位——面部一致改用参考图 + `the ... from Shot 1` 身份锚实现；"无字幕无水印"通常不需要写（H3 不倾向自己加字），画面不要文字就写 blank。
7. **@角色 改素材编号**：`@孟浩` 改为 Picture/素材编号 + 一句职责声明（`Picture 1 locks the protagonist's identity and costume`）。

反向迁移（H3 → Seedance）主要是降级：删字段名、时间码退回软提示、台词语法拆散进音频描述、屏上文字改回"无字 + 后期"。

## 四、两个模型通用的原则

写法语法之外，这些内容层原则在两边同样成立（详见 novel-to-storyboard 的 failure-modes.md）：

- 情绪写成面部肌肉动作，不写抽象词；
- 关键叙事道具锚定为构图约束（"始终清晰可见 + 画面位置"）；
- 连续性元素（头饰、服装细节）逐镜重复；
- 群像写死人数；
- 特效用物理描述代替文化词；
- 收尾镜用格局镜；
- 一次只改一处再重跑。

成片质检（切点、色温、响度、面部一致性）与模型无关，用 novel-to-storyboard 的 `qc_video.py`。
