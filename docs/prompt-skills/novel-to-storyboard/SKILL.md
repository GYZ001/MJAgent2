# 小说 → 视频分镜提示词

把叙事文本拆成"段"，每段 15 秒、内含 3-4 个镜头，由模型一次性生成多镜头片段，再逐段拼接成片。

这套方法的核心判断：**多镜头模式的价值不在省事，在于减少接缝。** 同一段里的 3-4 个镜头是一次生成的，人物长相、服装、光线在段内是锁死的；漂移只会发生在段与段的边界上。一条 105 秒的片子用 7 段结构只有 6 个接缝，用 10 秒单镜逐条拍则有 18 个接缝——一致性崩坏的概率差三倍。所以除非某个镜头特别关键需要单独控制，默认走分段多镜头。

## 工作流

按顺序做，不要跳步。前三步是根因控制——绝大多数成片质量问题是在这三步埋下的，靠改后面的提示词措辞补不回来。

### 第 1 步：提取叙事节拍

通读文本，列出**节拍表**（beat sheet）：每个节拍是一次情绪或信息的变化，不是一个句子。合并同质描写，删掉内心独白里无法视觉化的部分。

一个节拍 ≈ 一个镜头。节拍数决定成片长度：`总时长 ≈ 节拍数 × 4.5 秒`。

同时标出**全片的情绪转折点**——通常只有一个，是整条片子的脊椎。转折点决定色调怎么分段（见第 4 步）。

### 第 2 步：锁定交付参数

先问清楚、或者根据用户的使用场景推断，然后写在分镜文档开头：

- **画幅与分辨率**：横屏 1920×1080 / 竖屏 1080×1920。**竖屏不要接受任何低于 1080×1920 的档位**——分辨率是唯一后期完全无法挽救的东西，草稿档导出的片子在手机满屏看必然发糊。
- **总时长**：短视频平台开篇控制在 90-120 秒；正片开篇可到 3 分钟。
- **平台**：决定后面的混音目标（短视频 -14 LUFS）。

### 第 3 步：建角色与道具锚

给每个反复出现的人物和关键道具写一条设定，包含**至少三个可视觉验证的特征**（年龄段、脸型/体型、发型头饰、服装颜色材质、随身物）。年龄一定要写具体区间，"少年"会被模型渲染成从 12 岁到 25 岁的任何人。

然后为每个角色出**一张正面半身参考图**，在提示词里用 `@角色名` 引用。

不要用多角度九宫格设定图当参考——它会被读成好几个不同的人。一段里同框人物超过四个时，用一张合影参考图，比丢四张单人图稳。

### 第 4 步：分段

把节拍按**叙事单元**归入段，不是按时长平均切。一个段应该能用一句话概括（"他扔掉了理想"、"反派现身"），段与段之间是硬切。

每段 3-4 个镜头。动作段可以到 4 镜（每镜 3-4 秒），情绪段用 3 镜甚至 2 镜，让画面有呼吸。塞 5 镜以上会节奏过密。

**色调分段**：在情绪转折点把全片切成两个（偶尔三个）色调区，每个区一个明确的色温方向。转折本身要**单独成一个镜头**放在段的开头，镜头描述里写清"画面在两秒内由暖金褪成冷青"——把渐变交给跨段执行，模型会直接从硬切处就变成冷色，转折的过程就丢了。

### 第 5 步：写提示词

每段一条完整提示词，用这个骨架：

```
[质感锚] + 多镜头叙事，镜头之间硬切。
角色：@角色A = [三特征设定]；@角色B = [三特征设定]。

镜头1（约0-5秒）：[一个运镜] + @角色A [一个具体动作] + [场景] + [光影]
镜头2（约5-10秒）：[一个运镜] + @角色A [一个具体动作] + [场景] + [光影]
镜头3（约10-15秒）：[一个运镜] + @角色A [一个具体动作] + [场景] + [光影]

全片贯穿：音频[环境音/对白/配乐]；风格[色调/质感/画质]；
约束[面部一致、手指正确、人数锁定、无字幕水印]。
```

写的时候守住这七条，每条都对应一个实测踩过的坑，详见 `references/failure-modes.md`：

1. **镜头序号优先于时间码。** 模型对"镜头1/镜头2/镜头3"的顺序理解稳定，对"第 7 秒必须切"不稳定。秒数只写在括号里当软提示。要收紧节奏就减少镜头数，不要把时间码写得更死。
2. **一镜只给一个运镜。** 复合运镜（"先推后摇"）通常只执行第一个。要两种运动就拆成两个镜头。
3. **情绪必须写成面部动作。** "惊恐求救"会给你一张笑脸；"眉毛拧起、嘴大张、眼睛瞪圆、脖颈青筋绷紧"才有用。抽象情绪词模型没有稳定映射，具体肌肉动作有。
4. **关键道具要锚在画面里。** 写"葫芦在画面中始终清晰可见，位于画面右下"，而不是"葫芦砸入水面"——后者模型会拍一片水花，道具直接消失，叙事链条就断了。
5. **连续性元素每镜重复写。** 头巾、发髻、腰带、伤疤这类跨镜元素，要写进每一个 `镜头N` 的描述里，不能只在开头的角色定义里写一次。段与段的边界最容易掉这些。
6. **群像锁人数并加负向约束。** "画面中只有两名绿袍修士，不出现其他人物"。不锁人数，模型会自己加人，而且加进来的往往是面部崩坏的。
7. **特效用物理描述代替文化词。** "化作长虹"模型不知道该给什么，"一道细长银白光带以极高速度横穿画面并留下拖影"它知道。同理"仙气"写成"低垂的白色雾气贴地流动"。

另外两条结构性的：**收尾段的最后一镜必须是格局镜**（大远景/升起拉远），否则片子会"断"在人物中景上，没有落点。**片中所有文字**（牌匾、书信、标题）都交给后期合成，提示词里明确写"无字"——生成模型对汉字字形的还原极不稳定。

### 第 6 步：生成

按段生成，每段跑 2-3 个候选。先跑**四条基准段**：开场段（定人物和质感）、转折段（定色调分界）、反派/高潮段（定气质）、收尾段（定格局）。这四段通过了，其余段才有比对基准。

失败重跑时**一次只改一处**（主体、运镜、光线三者之一），否则无法判断是哪句话起了作用。

### 第 7 步：质检

成片出来后跑质检脚本，不要靠肉眼过一遍就下结论：

```bash
python scripts/qc_video.py <视频文件> --out <输出目录> --seg 15
```

脚本输出规格参数、切点分布、每段色温与锐度、响度、接触表和人脸比对图。验收门槛和读数方法见 `references/qc-checklist.md`。

### 第 8 步：定点重跑

拿质检结果定位失败镜头，**只把那几个镜头用 10 秒单镜模式单独重跑**再替换回去。不要整片重来——一条 7 段的片子重跑 3 个镜头的成本是重跑全片的十分之一。

单镜重跑时记得写"连续单镜头，不切换场景"，否则 10 秒档也会触发自动切镜。

## 输出格式

分镜文档用这个结构：

```markdown
# [片名] 分镜提示词（[N] 段 × [X] 秒）

**导演阐述**：[两三句话说清这条片子的视觉逻辑——不是剧情复述，是"为什么这么拍"]

## 交付参数
画幅 / 分辨率 / 总时长 / 平台 / 混音目标

## 角色与道具锚
[表格：标记 | 设定（三特征以上）]

## 分段提示词
### 段 01｜[X]s｜[一句话概括]（对应原文：[章节/段落]）
> [完整可复制的提示词]

[...每段一节...]

## 执行建议
[基准段顺序 / 已知风险点 / 剪辑衔接 / 后期文字合成清单]
```

每段提示词必须是**一整块可直接复制**的文本，不要把风格后缀拆出去让用户自己拼——复制粘贴时漏掉尾缀是最常见的人为失误。

## 一个完整的段落示例

原文节拍：*少年在山顶想通了、扔掉了装着理想的信物、目送它漂远。*

拆成 4 个镜头，暖色区，情绪段：

> 电影级预告片质感，多镜头叙事，镜头之间硬切。角色：`@少年` = 十六七岁清瘦书生，皮肤微黑，**青布束发头巾**，洗得发白的靛蓝文士长衫。
>
> **镜头1（约0-4秒）**：微距特写固定镜头，一双清瘦的手从怀中取出折皱的旧纸条，展开看一眼，重新折好塞进暗黄色老酒葫芦口，掌根用力压紧木塞，浅景深，背景是虚化的金色山野。
>
> **镜头2（约4-8秒）**：全景环绕镜头，`@少年`（**戴青布头巾**）站起走到悬崖边缘，衣衫被山风灌满鼓起，后仰蓄力，手臂猛地挥出，葫芦脱手飞向画面深处。
>
> **镜头3（约8-12秒）**：高空俯拍跟随下坠，**暗黄色葫芦始终位于画面中心清晰可见**，在空中翻滚坠落砸入湍急大河激起白色水花，随后被急流卷向远山，夕阳把河面染成流动的碎金。
>
> **镜头4（约12-15秒）**：面部特写固定镜头，`@少年`（**戴青布头巾**）站在崖边目送远方，眼眶泛红有水光，深吸一口气，下颌绷紧，眉头由紧锁转为舒展，眼神从涣散聚焦。
>
> 全片贯穿：音频为纸张摩擦声、木塞闷响、猎猎风声、落水声；风格为东方写实电影质感，古装正剧，夕阳暖金与青灰色调，胶片颗粒感，4K 超清；约束为人物面部清晰不变形，服装发型全程一致，手指数量正确，无字幕、无水印、无现代物件。

加粗的三处就是第 5 步里的规则 4、5、3 在起作用：道具锚定、头饰逐镜重复、情绪写成面部动作。去掉这三处，实测结果是葫芦在落水镜里消失、头巾在段边界掉了、最后一镜的"释然"变成面无表情。
