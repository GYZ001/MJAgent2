## 1. 多镜头模式怎么触发

没有开关，靠**时长参数 + 提示词写法**一起诱发。四件事同时做：

**时长拉到 15 秒。** 这是单次生成上限，也是最容易触发多场景的档位。4-6 秒基本不会自动切镜；10 秒档会**偶尔**自作主张切镜（实测一条 19 镜 × 10 秒的片子里有 5 个镜头被模型自己切成了两三镜）。这一点很重要：10 秒不等于"单镜可控"，要单镜必须显式声明。

**开头下多镜头意图锚。** 第一句写入暗示词：

> 电影级预告片质感，多镜头叙事，镜头之间硬切。

"预告片""多镜头叙事""电影级镜头切换"是有效触发器。

**用镜头序号排列，不要死钉时间码。** 模型内部把视频拆成"空间层"（画面里有什么）和"时间层"（怎么随时间变化），它对镜头**顺序**的理解远比对**精确秒数**稳定。把片段钉在固定秒数上往往让结果更糟。秒数写在括号里当软提示即可，模型可能采纳也可能自己找节奏。

**每段控制在 3-4 镜。** 5-7 个场景是 15 秒的效果上限，塞更多能跑但节奏过密。实测：写 3 镜的段落，模型有时会给到 4 镜；写 4 镜的段落基本不会超过 5 镜。所以想要 4 镜就写 3 镜，留出模型自由发挥的余量。

## 2. 提示词的成分顺序

一个镜头描述的推荐顺序：

```
运镜 → 主体（@引用）→ 一个具体动作 → 场景 → 光影
```

把运镜放最前，因为它决定整个镜头的空间关系；把光影放最后，因为它是修饰层。中间的"一个具体动作"是这句话的核心——模型对动词的执行力远强于对形容词的执行力。

反面写法："一个男人在街头紧张地奔跑，画面很有电影感。"
——没有运镜、没有具体动作（"紧张地"不是动作）、没有场景细节、"电影感"是空词。

正面写法："中景手持跟拍，男人低头护住怀中纸袋，穿过雨夜的窄巷，霓虹在积水里碎成一片红。"

## 3. 运镜词表

**一个镜头只用其中一个。** 复合运镜通常只执行第一个。

| 类别 | 词 | 适用 |
|---|---|---|
| 推 | 缓慢推进 / 快速推近 | 情绪聚焦、建立压迫感 |
| 拉 | 缓慢拉远 / 急速拉远 | 揭示环境、收尾格局 |
| 摇 | 横摇 / 快速横摇 | 跟随动作、扫过群像 |
| 升降 | 缓慢升起 / 俯拍下降 | 起幅落幅、坠落 |
| 跟 | 手持跟拍 / 剧烈跟拍 | 追逐、慌乱、主观感 |
| 环绕 | 环绕镜头 | 强调人物姿态、仪式感 |
| 固定 | 固定镜头 / 固定机位 | 对话、静默、恐怖片式凝视 |

景别六级：极特写 / 特写 / 近景 / 中景 / 全景 / 大远景。

常用叙事序列：
- 大远景 → 中景 → 特写：开场建立
- 特写 → 拉远至全景：揭示反转
- 中景 → 正反打特写 → 双人中景：对话场景

## 4. 参考图与角色一致性

- 用 `@角色名` 在提示词里引用参考图，**每个 `镜头N` 里都要重新点名**，不能只在开头写一次就指望模型记住三次切镜。
- 参考图用**单张正面半身、光线均匀**的图。多角度九宫格设定图会被读成不同的人。
- 一次可混合上传多种素材（图片 / 视频 / 音频），总数有上限（约 12 个文件）。素材多时优先保证对输出影响最大的那几张。
- 同框人物超过四个时，用一张合影参考图，比丢多张单人图稳。
- 参考视频可以用来复刻运动，比文字描述运镜更准。

## 5. 生成参数

| 参数 | 建议值 | 说明 |
|---|---|---|
| duration | 15 | 上限，也是多镜头档 |
| resolution | 1080p | 竖屏用 1080×1920，横屏 1920×1080 |
| ratio | 16:9 / 9:16 | 按投放平台定 |
| 帧率 | 24 | 电影感；动作多可考虑更高 |

**分辨率不要用草稿档。** 实测 496×864 导出的竖屏成片在手机满屏播放明显发糊，且后期无法挽救——这是唯一一个"生成时省了、后期救不回"的参数。

## 6. 反向：怎么要一镜到底

长时长档默认倾向切镜。要连续单镜头必须显式写：

> 连续单镜头，不切换场景，不切换机位。

并且把镜头数写成 1，动作写成一条连贯的动作链（"A 导致 B，B 触发 C"），不要出现"然后画面切到"这类词。

## 7. 与其他视频模型的差异

Seedance 2.0 的两个特点会影响提示词写法：

- **原生音画同生**：音频跟画面一起生成，对白、音效、配乐都可以写进提示词，不需要后期单独铺音轨。所以"全片贯穿"那段一定要写音频，留空等于放弃一半信息量。
- **物理表现较强**：碰撞、布料撕裂、落体这类交互写具体一点值得——"衣袍在气流中向后绷直并高频抖动"比"衣袂飘飘"效果好得多。

如果目标模型不是 Seedance（可灵、即梦其他版本、Veo 等），多镜头触发方式和参数会不同，**先确认版本再套用本文**，不要默认迁移。
